What has this to do with YEH?

In this example, we use YEH as Subscriber System to subscribe and dispatch Events.

YEH provides 2 ways to subscribe:

// Subcribe immediately via document selector in the constructor
constructor() {
    super({
        document: [
            { type: 'worker-result', handler: 'displayResult' },
        ]
    });
}

// Or add the listener on the fly. It will listen immediately after adding
this.addEvent('document', { type: 'worker-result', handler: 'displayResult' });
