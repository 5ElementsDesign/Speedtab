CLEANUP

Speedtab tries to keep cleanup predictable. When you delete something higher in the structure, the related child content goes with it.

  • Delete Page removes the page, its modules, their tabs, notes, feed sources, live feed items, archived feed items, and collections.
  • Delete Module removes that module and everything stored inside it, including collections, bookmarks, notes, feeds, and archived feed items.
  • Delete Tab in the module header really means deleting a collection tab, so all content inside that tab is removed with it.

What happens to assets?

Assets such as bookmark previews, uploaded favicons, note images, and backgrounds are not blindly deleted the moment one item disappears. Speedtab runs orphan cleanup to remove assets that are no longer referenced anywhere.

  • If another bookmark, note, feed, or page still uses an asset, it stays.
  • If nothing references an asset anymore, cleanup can remove it.
  • This helps avoid broken previews while still preventing the database from collecting dead files forever.

Delete actions remove content immediately. Asset cleanup is reference-aware.
