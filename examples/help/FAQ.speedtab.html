FAQ

Where is my data stored?

By default, Speedtab stores workspace data locally in this browser profile.

How do I move my workspace to another browser?

Use Data Exchange to export a local backup file, then import it in another browser.

Is WebDAV the same as live merge sync?

No. WebDAV sync uses explicit push and pull actions. A push replaces the live remote export with the local one.

Can I keep different layouts on phone and desktop?

Mobile layout already collapses to a single column when space gets narrow. More local-only layout tuning may come later.

Can I reset Speedtab completely?

Yes. The Cleanup modal includes a guarded full database reset for the current browser profile.

What is the safest workflow?

  • Keep a local export
  • Use WebDAV as an extra backup layer if you want remote storage
  • Check remote contents before pulling or pushing
