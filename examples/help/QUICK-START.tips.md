Title: Quick Start Tips
Type: text
Color: success

1. Right click page tabs to edit them.
2. Use module tabs to separate bookmarks, notes, or feed groups.
3. Try `Module Width` together with `Modules per Row` to build custom layouts.
4. Use `Quicklinks mode` for compact favicon-first bookmark grids.
5. Open multiple notes at once and keep them floating while switching pages.
6. Use `Data Exchange` for export/import and optional WebDAV sync.
7. Use `Cleanup` when you want to remove stale data or reset the local profile.

Speedtab is designed to be explored. Create a page, add a module, and start shaping it.
