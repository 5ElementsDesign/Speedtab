About Speedtab

Speedtab started as a personal experiment inspired by Opera's old Speed Dial experience. The goal was simple: open a new tab and land in a place that feels useful immediately.

The first version was a web app. That made it feel available everywhere and gave it a built-in multi-device sync feeling, but it also meant a permanent server dependency, online-first behavior, and the full weight of maintaining a web application stack.

The extension version keeps the idea, but removes the web-app burden.

Why the extension exists

  • No server required for the normal experience
  • Local-first storage with explicit export and import
  • Optional WebDAV sync instead of mandatory online infrastructure
  • A layout system shaped around real daily workflows, not generic tiles
Phase Main idea
WebApp Always online, accessible anywhere, server-backed
Extension Local-first, faster startup, less infrastructure, more privacy control
Today Flexible modules, floating notes, widgets, export/import, and optional WebDAV backup

Speedtab still aims for the same feeling as the original idea: log in or open a new tab and feel at home immediately.
