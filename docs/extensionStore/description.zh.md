Speedtab：超快速、本地优先的浏览器新标签页工作区，绝不跟踪您的任何隐私。基于纯原生 JavaScript 构建，零框架依赖，内存占用极小。

Speedtab 将默认的浏览器新标签页替换为快速、信息密集、本地优先的快捷拨号和高效生产力仪表板。无需注册账号，没有后台服务器，绝无追踪行为，支持可选的远程同步。您的数据，完全由您掌握。

为您不同的使用场景构建自定义起始页，将其拆分为模块化网格，并通过标签页组织您的内容。将视觉书签、RSS/Atom 订阅源、便签、代码片段、链接列表、HTML 组件以及加密私密笔记无缝集成在同一个极速、统一的工作区中。

Speedtab 专注于结构、速度和完全的数据所有权：

- 无需注册或登录账号
- 没有任何第三方后台服务器
- 无需强制绑定云服务
- 浏览器内部真正的本地优先存储
- 便携式导入与导出，保障数据完全自由

您可以通过 Speedtab 实现：

- 将书签整理到页面、模块和自定义标签页中
- 体验专为您的工作流程打造的高性能经典快捷拨号（Speed Dial）
- 为书签上传本地预览图和自定义 Favicon 图标
- 创建文本、代码、链接、自定义 HTML 以及加密笔记
- 利用 YaiTabs 在 HTML 笔记内构建无限深度嵌套的标签页结构
- 直接在新标签页起始页阅读 RSS/Atom 订阅源
- 跟踪文章已读/未读状态，并附带自定义备注归档感兴趣的条目
- 自定义主题视觉效果、网格布局和 CSS 背景
- 通过平滑的导入/导出在不同浏览器配置文件之间无缝迁移工作区

Speedtab 完全遵循本地优先原则。应用数据安全地保存在浏览器本地 IndexedDB 中。订阅源抓取由扩展后台 service worker 安全执行。加密笔记在客户端使用 AES-GCM 和 PBKDF2-SHA256 进行保护，您的密码绝不会离开您的设备。

打造真正强大、功能丰富的新标签页工作区，告别泛用的起始页和侵犯隐私的云端仪表板。

----------------------------------------
SPEEDTAB 功能全景解析
----------------------------------------

应用外壳与工作区架构
• 全屏应用外壳，为工作区或分类提供可自定义的多页面导航。
• 支持对页面、模块、集合和单个条目进行拖拽排序。
• 基于 YaiJS 和 YEH（Yai 事件总线）的事件委托核心，在单个共享运行时上运行，具有 O(1) 可扩展性，零虚拟 DOM 开销。
• 极致轻量级核心，响应迅速，无需虚拟 DOM。
• 完整的键盘导航和 WCAG 2.1 AA 无障碍支持（方向键、Home、End、Enter、空格键）。
• 全局防抖搜索，支持即时定位、绝对定位结果层和页内高亮提示。
• 外观与布局控制：
  - 全局默认壁纸及单页面背景重写。
  - 自定义 CSS 背景编辑器，支持实时语法验证和渐变/颜色存档。
  - 单模块布局控制：自动、多列跨度及全宽网格布局。
  - 模块最小高度控制及单模块内容间距重写。
  - 外壳宽度边界和小组件栏位置设置（顶部或底部）。

视觉书签模块
• 视觉 Tile 渲染，支持自定义 Favicon 或上传预览图。
• 内置裁剪工具（CropperJS），在保存前将上传的本地预览图裁剪为固定比例。
• 资源浏览器和 Favicon 管理器：
  - 从 IndexedDB 资源表中选择已保存的 Favicon。
  - 直接上传自定义 Favicon。
  - 暗色/透明低对比度 Favicon 的自动检测与修复（保存前添加纯色背景层）。
• 导航设置：独立切换每个模块在新标签页或当前标签页打开的行为。
• 布局与 Tile 自定义：
  - 默认模式（106x60px 视觉预览 Tile）。
  - 快捷链接模式 Quicklinks（48x48px 紧凑 Favicon 网格）。
  - 大 Tile 模式 Big Tiles（154x80px 放大预览）。
  - 可选标题显示在 Tile 下方的文本标注模式。
  - 支持带透明度的 Tile 级自定义背景颜色。

快捷拨号模块 (SPEED DIAL)
• 独立的全宽快捷拨号表面，带有极简、透明的模块外壳。
• 居中的 16:9 Tile，支持调节高度及顶部/居中/底部内容对齐。
• 可选标签页、内联添加按钮及全页高度模式。
• 支持本地快捷拨号图片资源及单图片外边距调整。
• 基于 Favicon 提取 Tile 主色调，无需外部截图或图片服务即可构建统一美观的视觉效果。

笔记与互动笔记引擎
• 五种笔记内容类型：
  - HTML 笔记：
    * 经过安全净化的 HTML 渲染，支持资源占位符和内联图片。
    * 支持在笔记内容中直接宿主实时、全互动的 YaiTabs 嵌套标签页结构。
    * 基于属性的 Style API（通过 data-st-* 属性控制宽高、边距、弹性盒、网格、边框、圆角、阴影、字号及颜色），无内联样式安全漏洞。
    * 预设宏一键插入布局骨架和组件模板。
  - 文本笔记：纯文本编辑器，适合快速无格式记录。
  - 链接笔记：将按行排列的原始 URL 自动转换为可点击的链接列表；非 URL 文本块渲染为样式化引用块。
  - 代码笔记：等宽字体代码片段存储，通过 Highlight.js 提供自动语法高亮。
  - 加密笔记 (Crypt)：客户端加密的私密笔记，基于 AES-GCM 和 PBKDF2-SHA256（310,000 次迭代）。需要密码解密，密码绝不存储或缓存。
• 笔记编辑器界面模式：
  - 默认分屏编辑器，支持 HTML 笔记的实时预览切换。
  - Flying Config 悬浮配置：在专门的聚焦配置界面中编辑深层嵌套的 HTML 笔记内容，无需在层层标签页中逐个查找。
  - 本地 Quicknote 便签：在顶部栏随时调用的本地便签，独立于工作区导出存储。
• 悬浮窗口系统：笔记可弹出为可拖拽、可调整大小、可控制层级的悬浮窗口，在浏览器刷新后依然保持位置与尺寸。

订阅源阅读器模块 (FEED READER)
• 集成 RSS/Atom 订阅源阅读器，可部署在任何页面模块网格中。
• 订阅源管理：从标准网站 URL 添加、验证并自动发现隐藏的 RSS/Atom 订阅源。
• 阅读功能：
  - 源筛选及可自定义的可见文章数量限制。
  - 文章已读/未读状态跟踪，支持批量标记。
  - 文章归档管理器，可将文章保存至本地并添加自定义备注。
  - 扩展阅读视图：将订阅源模块放大为全宽阅读视图，支持调节阅读列宽度。
  - 订阅源内本地文本筛选，实时搜索已加载的文章。
  - 当当前标签页可见时，可选的单模块自动刷新循环。
  - 由后台 service worker 安全执行跨域订阅源抓取。

小组件栏与实用工具
• 模块化小组件栏，可放置在主工作区页面的上方或下方。
• 时钟与时间工具：
  - 可切换数字或模拟时钟显示模式。
  - 本地化日期/时间字符串格式化、标记插入助手、自定义字体大小、对齐及元素颜色。
  - 本地优先的秒表和多定时器工具，基于零损耗真实 DOM 循环运行。
• 天气系统：
  - 紧凑的工具栏温度显示，支持自定义地点搜索和单位切换（摄氏度/华氏度）。
  - 可直接从小组件调出详细的 7 天天气预报弹窗。
• 远程同步状态指示器，提供直观的健康状况反馈。

右键菜单捕获与收件箱引擎
• 浏览器右键菜单集成：右键点击任何网页或选中文本，即可执行“追加到便签”而无需切换标签页。
• 实时待办计数器：后台标签页标题动态更新未处理队列数量（例如：INBOX [3] - Speedtab）。
• 高级收件箱管理器：顶部专用抽屉，用于审查、编辑、筛选并将捕获的剪贴整理到具体的书签或笔记模块中。

数据所有权、存储与远程同步
• 100% 本地优先存储：所有应用状态、模块结构和二进制资源均通过 Dexie 保存在客户端 IndexedDB 中。
• 便携式 JSON 数据交换：
  - 带有校验和验证的 JSON 导出文件 (speedtab-export-<checksum>.json)。
  - 具备身份感知的记录合并引擎，可在不同浏览器配置文件间迁移工作区而不会产生重复记录。
  - 独立的导入/导出工具界面 (import-export.html)。
• 可选的远程云端同步：
  - WebDAV 同步：支持手动推送 (push)、拉取 (pull)、远程内容对比及状态检查。
  - Google Drive 同步：基于 chrome.identity 授权同步至用户隐藏的应用数据文件夹，包含自动推送定时器及远程工作区健康度验证。

系统维护与网格排序器
• 专用网格排序器 (sorter.html)：独立的配置页面，用于重组工作区页面层级、内联编辑标签页标题以及执行级联删除。
• 系统清理管理器：扫描本地数据库表，检测并清理孤立记录、未使用的二进制资源以及失效的 Favicon。

国际化与原生本地化
• 基于原生 chrome.i18n 构建扩展国际化。
• 针对英语、德语、荷兰语、土耳其语、印地语、俄语和中文（简体）提供完整的用户界面翻译及本地化示例工作区。
