Speedtab: сверхбыстрое локальное рабочее пространство для новой вкладки, которое не следит за вами. Создано на чистом Vanilla JS, без фреймворков и с минимальным потреблением памяти.

Speedtab заменяет стандартную страницу новой вкладки браузера на быстрый, информативный локальный рабочий стол быстрого набора и панель продуктивности. Без аккаунта. Без стороннего сервера Speedtab. Без отслеживания. С опциональной удаленной синхронизацией. Только ваши данные и только ваш контроль.

Создавайте пользовательские стартовые страницы для разных задач, разделяйте их на модульные сетки и организуйте контент по вкладкам. Объединяйте визуальные закладки, RSS/Atom-ленты, быстрые заметки, фрагменты кода, списки ссылок, HTML-компоненты и зашифрованные личные заметки в едином сверхбыстром рабочем пространстве.

Speedtab спроектирован для структуры, скорости и полного владения своими данными:

- не требуется учетная запись
- нет стороннего серверного сервиса Speedtab
- не требуется облачный аккаунт
- честное локальное хранение внутри браузера
- портативный экспорт/импорт для полной свободы данных

Что вы можете делать с помощью Speedtab:

- организовывать закладки по страницам, модулям и пользовательским вкладкам
- использовать классический высокопроизводительный быстрый набор (Speed Dial), адаптированный под ваши рабочие процессы
- загружать локальные изображения предпросмотра и собственные значки (favicon) для закладок
- создавать текстовые заметки, заметки с кодом, списками ссылок, пользовательским HTML и зашифрованные заметки
- создавать бесконечные вложенные структуры вкладок внутри HTML-заметок благодаря YaiTabs
- читать RSS/Atom-ленты прямо на стартовой странице новой вкладки
- отслеживать состояние прочитанных/непрочитанных публикаций и архивировать интересные статьи с комментариями
- настраивать визуальное оформление, сетки макета и CSS-фоны
- переносить рабочее пространство между профилями браузера с помощью удобного экспорта/импорта

Speedtab полностью локален. Данные приложения надежно хранятся в IndexedDB внутри вашего профиля браузера. Загрузка лент выполняется непосредственно самим расширением через фоновый service worker. Зашифрованные заметки защищены на стороне клиента с помощью AES-GCM и PBKDF2-SHA256. Ваши пароли никогда не покидают устройство.

Получите реальное, мощное рабочее пространство для новой вкладки вместо стандартной стартовой страницы или облачной панели, собирающей персональные данные.

ПОЛНЫЙ ОБЗОР ВОЗМОЖНОСТЕЙ SPEEDTAB

ОБОЛОЧКА ПРИЛОЖЕНИЯ И АРХИТЕКТУРА РАБОЧЕГО ПРОСТРАНСТВА
• Оболочка приложения на весь экран с многостраничной навигацией для категорий и рабочих процессов.
• Перетаскивание (drag-and-drop) для изменения порядка страниц, модулей, коллекций и элементов.
• Ядро на базе делегирования событий YaiJS и YEH (Yai Event Hub), работающее в единой среде исполнения с O(1) масштабируемостью и нулевыми накладными расходами виртуального DOM.
• Сверхлегкое ядро с адаптивным интерфейсом без виртуального DOM.
• Полная поддержка навигации с клавиатуры и доступности по стандарту WCAG 2.1 AA (стрелки, Home, End, Enter, Пробел).
• Глобальный поиск в шапке с задержкой ввода, мгновенным переходом и подсветкой элементов на странице.
• Управление внешним видом и макетом:
  - Глобальный фон по умолчанию и переопределение фона для отдельных страниц.
  - Редактор фонов CSS с валидацией синтаксиса и архивом сохраненных градиентов/цветов.
  - Настройки макета каждого модуля: авто, охват колонок и полноширинные сетки.
  - Управление минимальной высотой модулей и отступами содержимого.
  - Настройка максимальной ширины оболочки и положения панели виджетов (сверху или снизу).

МОДУЛЬ ВИЗУАЛЬНЫХ ЗАКЛАДОК
• Отрисовка плиток с поддержкой пользовательских значков сайтов (favicon) или загруженных изображений предпросмотра.
• Встроенный инструмент кадрирования (CropperJS) для обрезки загружаемых изображений под фиксированный размер плитки.
• Браузер ресурсов и менеджер значков страниц:
  - Выбор из всех значков, сохраненных в таблицах IndexedDB.
  - Прямая загрузка пользовательских favicon.
  - Автоматическое обнаружение и исправление темных/прозрачных значков с низким контрастом (добавление чистого фонового слоя перед сохранением).
• Настройки навигации: переключение открытия ссылок в текущей вкладке или новой фоновой/активной вкладке.
• Настройка макета и плиток:
  - Стандартный режим (плитки предпросмотра 106x60px).
  - Режим быстрых ссылок Quicklinks (компактная сетка 48x48px с акцентом на значки).
  - Режим больших плиток Big Tiles (увеличенные плитки 154x80px).
  - Опциональный режим с названием под плиткой.
  - Пользовательские цвета фона плиток с поддержкой прозрачности.

МОДУЛЬ БЫСТРОГО НАБОРА (SPEED DIAL)
• Отдельная полноширинная поверхность быстрого набора с минималистичной прозрачной оболочкой.
• Плитки 16:9 по центру с регулируемой высотой и выравниванием содержимого по верху, центру или низу.
• Опциональные вкладки, кнопка добавления плитки и режим на всю высоту страницы для классических макетов.
• Локальные ресурсы изображений быстрого набора с индивидуальными отступами.
• Цвета плиток на основе значков сайтов создают гармоничный вид без внешних сервисов скриншотов.

ЗАМЕТКИ И ИНТЕРАКТИВНЫЙ ДВИЖОК ЗАМЕТОК
• Пять типов содержимого заметок:
  - HTML-заметки:
    * Очищенная отрисовка HTML с плейсхолдерами ресурсов и встроенными изображениями.
    * Поддержка интерактивных вложенных вкладок YaiTabs прямо внутри контента заметки.
    * Style API на основе атрибутов (data-st-* для ширины, высоты, отступов, flexbox, grid, рамок, радиуса скругления, теней, типографики и цветов) без уязвимостей встроенных стилей.
    * Шаблоны макетов и компонентов для быстрой вставки в редактор.
  - Текстовые заметки: Редактор обычного текста для быстрых записей.
  - Заметки со ссылками: Превращает список URL в кликабельные ссылки; текстовые блоки оформляются как цитаты.
  - Заметки с кодом: Хранение кода с моноширинным шрифтом и автоматической подсветкой синтаксиса через Highlight.js.
  - Зашифрованные заметки (Crypt): Заметки с клиенским шифрованием AES-GCM и PBKDF2-SHA256 (310 000 итераций). Требуют пароль для расшифровки; пароли никогда не сохраняются и не кэшируются.
• Режимы редактора заметок:
  - Стандартный редактор с разделенным экраном и предпросмотром для HTML-заметок.
  - Flying Config: Редактирование глубоко вложенных вкладок HTML-заметок из отдельной фокусированной панели без поиска по вложенным вкладкам.
  - Локальная быстрая заметка (Quicknote): Быстрый блокнот в шапке, хранящийся независимо от экспорта рабочего пространства.
• Система плавающих окон: Заметки можно выносить в перетаскиваемые плавающие окна с изменением размера, сохраняющие положение и размеры при перезагрузке.

МОДУЛЬ ЧТЕНИЯ ЛЕНТ НОВОСТЕЙ (FEED READER)
• Встроенный модуль чтения RSS/Atom, размещаемый в любой сетке модулей.
• Управление источниками: добавление, проверка и автоматический поиск скрытых RSS/Atom лент на сайтах.
• Возможности чтения:
  - Фильтрация источников и настраиваемый лимит видимых статей.
  - Отслеживание прочитанных и непрочитанных статей с массовыми действиями.
  - Архив статей с возможностью сохранения материалов и добавления пользовательских комментариев.
  - Расширенный режим чтения: Разворачивание модуля ленты на полную ширину с выбором ширины колонки чтения.
  - Локальный поиск по тексту для фильтрации загруженных статей в реальном времени.
  - Опциональный автоматический цикл обновления во время активности вкладки.
  - Безопасная загрузка междоменных лент через фоновый service worker.

ПАНЕЛЬ ВИДЖЕТОВ И ИНСТРУМЕНТЫ
• Модульная панель виджетов, расположенная над или под основными страницами.
• Часы и время:
  - Переключаемые цифровые или аналоговые часы.
  - Форматирование даты и времени, токены, пользовательский размер шрифта, выравнивание и цвета элементов.
  - Секундомер и мульти-таймер, работающие на реальном DOM без лишних нагрузок.
• Погода:
  - Компактный индикатор температуры с поиском местоположения и переключением единиц (Цельсий/Фаренгейт).
  - Детальный 7-дневный прогноз погоды прямо из виджета.
• Индикатор состояния удаленной синхронизации.

ЗАХВАТ ИЗ КОНТЕКСТНОГО МЕНЮ И ВХОДЯЩИЕ
• Интеграция с контекстным меню браузера: Кликните правой кнопкой мыши по странице или выделенному тексту для добавления в быструю заметку без переключения вкладок.
• Счетчик ожидающих элементов: Динамический заголовок фоновой вкладки отображает количество необработанных элементов (например: INBOX [3] - Speedtab).
• Менеджер входящих: Специальная панель в шапке для просмотра, редактирования, фильтрации и раскладки захваченных фрагментов по модулям.

ВЛАДЕНИЕ ДАННЫМИ, ХРАНЕНИЕ И УДАЛЕННАЯ СИНХРОНИЗАЦИЯ
• 100% локальное хранение: Все состояние приложения, структура модулей и файлы хранятся в IndexedDB браузера через Dexie.
• Портативный обмен данными JSON:
  - Файлы экспорта JSON с контрольной суммой (speedtab-export-<checksum>.json).
  - Умный движок объединения записей для переноса рабочих пространств между профилями без дублирования.
  - Отдельная страница экспорта/импорта (import-export.html).
• Опциональная удаленная облачная синхронизация:
  - Синхронизация WebDAV: Ручная отправка (push), получение (pull), сравнение содержимого и проверка статуса.
  - Синхронизация Google Drive: Авторизация через chrome.identity в скрытую папку приложения Google Drive, включая таймер авто-синхронизации и проверку целостности.

ОБСЛУЖИВАНИЕ СИСТЕМЫ И СОРТИРОВКА СЕТКИ
• Отдельный сортировщик сетки (sorter.html): Страница конфигурации для реорганизации иерархии страниц, редактирования заголовков и каскадного удаления.
• Менеджер очистки системы: Сканирование таблиц локальной базы данных для поиска и удаления осиротевших записей, неиспользуемых ресурсов и устаревших значков страниц.

ИНТЕРНАЦИОНАЛИЗАЦИЯ И ЛОКАЛИЗАЦИЯ
• Локализация расширения построена на нативном chrome.i18n.
• Полный перевод интерфейса и локализованные примеры рабочих областей для английского, немецкого, нидерландского, турецкого, хинди, русского и китайского (упрощенного) языков.
