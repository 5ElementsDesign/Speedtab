Speedtab – Speed Dial Next

Speedtab replaces the default browser new-tab page with a dense, fast workspace for visual bookmarks, typed notes, RSS/Atom feeds, local assets, and portable exports.

Privacy Policy Chrome Web Store GitHub Repository

Highlights

  • Visual bookmarks with preview images, custom favicons, quicklinks mode, and title-below-tile mode

  • Notes with text, code, links, HTML, and encrypted client-side content

  • Integrated RSS/Atom feed reader with archiving, unread state, and focused reading mode

  • Sortable pages, modules, tabs, and content on a dedicated management surface

Architecture

  • Runs fully local-first in the browser with IndexedDB via Dexie

  • Rebuilt on YaiJS, YaiTabs, and Ypsilon Event Handler (YEH)

  • Delegation-first event model with nested tab interfaces across the shell and HTML notes

  • No cloud backend required for workspace storage
